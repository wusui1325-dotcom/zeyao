# 擇要

擇要是一款 Android 應用：打開任何網頁時先出現小型「驗證中」浮窗，用你選定之 API 的 flash 模型、最輕量參數判斷是否為新聞。若是，立刻進入擇要頁並以串流寫出摘要；若不是，則照常打開原頁。擇要頁一出現就有「返回」與「進入」兩個按鈕，不必等模型或文章擷取完成。

- **返回**：關閉擇要頁，不繼續打開原文。
- **進入**：關閉擇要頁，放行原文。
- 摘要為繁體中文短訊，適合數秒內讀完。
- 這是 Wusper 相關的獨立專案，不是 GameHub 的一部分。

目前版本：`6.9.5`

6.9.5 把攔截到驗證判斷的路徑再壓快一輪，產品行為不變。設置與金鑰改走記憶體快取，驗證請求在「驗證中」浮窗出現前就先發出，一般網址不再為分類多等一輪轉址或磁碟讀取；離開浮窗會取消仍在進行的判斷請求。搜索提取仍只在進入擇要頁之後才跑，不會拖慢驗證。請蓋過 6.9.4 再試。

6.9.4 把設置裡的生成參數收進「其他 → 模型與參數」專頁。搜索提取、擇要、驗證三個角色可各自設定型號、溫度、強度與 API 金鑰；角色金鑰留空則沿用共用金鑰，現有使用者不必重填三把。強度會真正送到請求裡：搜索影響關鍵詞篇幅與結果數量，擇要影響摘要篇幅與推理力度，驗證影響判斷回覆篇幅與力度（預設仍是最輕量）。服務商維持全域設定。請蓋過 6.9.3 再試。

6.9.3 再修一輪 6.9.0 一開啟就閃退的問題。6.9.1 已先避開冷啟動讀取語言時 `applicationContext` 仍為空的情況；6.9.2 修好設置裡「設為預設瀏覽器」沒有反應。若你是蓋過舊版安裝、主畫面已有紀錄，6.9.0 仍可能在畫出新的篩選晶片、滑動刪除或釘選圖示時於正式版（R8）崩潰。現改回與 6.8 相同、已驗證可在正式版執行的元件來呈現篩選、釘選與刪除（刪除改為列上按鍵，仍可復原），設置讀取失敗會安全回退，生物辨識鎖定在裝置不支援或驗證組合不被接受時也不會讓應用崩潰。請蓋過 6.9.0 至 6.9.2 再試。

6.9.2 修正設置裡點「設為預設瀏覽器」沒有反應的問題。先前只要系統提供瀏覽器角色，就一律送出角色申請 Intent；若擇要已經是預設瀏覽器，該畫面會立刻結束、看起來像沒點到。角色申請也改以 `startActivityForResult` 啟動，並在申請不可用或失敗時依序改開系統的預設應用程式、依預設開啟，以及應用程式詳細資料頁；若全部打不開，會顯示提示而不是靜默失敗。

6.9.1 修正介面語言在 Application 尚未附加、Application Context 還未就緒時就被讀取的問題：改為只用 `attachBaseContext` 傳入的 Context 讀取語言設定；若此時仍讀不到偏好，則安全回退為預設繁體中文。

6.9.0 在 6.8.0 之上再修一輪實際會踩到的問題，並補上幾個符合擇要定位的小功能：

- 修正同一網站不同文章被當成同一則、進入後整站冷卻過久的問題；冷卻改為針對同一則文章，主機短暫放行只為讓原文載入。
- 分類與摘要用的網址正規化不再依賴 Android 單元測試中不完整的 `Uri` 實作；冷卻計時可在測試中注入，相關單元測試會通過。
- 摘要失敗等提示改走字串資源，繁中、簡中、英文會一併更新。
- 驗證浮窗在未完成判斷就被系統關掉時，會釋放仍被抓住的連線，避免原文卡住。
- 已結束的擇要 session 會從記憶體清掉；紀錄寫入用世代號避免舊快照覆蓋新內容。
- 主畫面可搜尋主機、依釘選／失敗篩選；紀錄可釘選、左右滑刪除並復原，詳情可分享、複製、打開原文、重新摘要與調整字級。
- 擇要頁可複製摘要、調整字級，並可選「不再攔截此網站」；略過清單在設置中管理。
- 可選生物辨識鎖定主畫面（預設關閉）。驗證浮窗與擇要頁不會被擋住。離開設置等系統頁回來時也不會立刻重鎖。

6.8.0 是針對 6.7.0 的一輪修正與效能整理，不是再一次功能堆疊。實際改動：

- 修正分類失敗或空白回覆被當成「不是新聞」並寫入快取的問題；超時或無法判斷時改為直接打開放行。
- 驗證逾時從 12 秒縮為 8 秒，離開驗證浮窗時取消請求，避免卡住。
- 一般新聞網址不再先做 HTTP HEAD 跟轉址；只有已知短網址才會網路解析。
- 串流摘要不再每個 token 重寫最近紀錄檔，改為記憶體立即更新、磁碟延遲寫入。
- 進入擇要頁時不再為每次畫面重建多開一個永不取消的 session 收集器。
- 設置裡「開啟 HTTPS 解密」會先出現確認框；並補回「擇要憑證」安裝列。
- 去掉重複的搜索開關、攔截次數與「僅解密新聞域名」區塊；生成參數滑桿改在放手後才儲存。
- 高對比主題改為真正的黑白高對比，不再只是深色模式。
- 介面語言在冷啟動就會套用；繁中、簡中、英文文案對齊，主畫面／設置／擇要頁少用寫死的中文。
- 擇要頁「返回／進入」TalkBack 標籤與較窄螢幕的操作列換行；紀錄詳情會跟隨生成進度更新。

## 運作方式

首次啟動會進入全頁引導：先選擇 AI 服務商（DeepSeek、OpenAI、Google Gemini、Anthropic Claude、xAI Grok），再輸入該服務商的 API Key，然後在載入頁初始化接口並寫入預設生成參數：

- 關閉深度思考
- 高強度／高 reasoning effort（各家按官方欄位對應，能送的就送）
- 溫度 1.2
- 最多 1000 tokens
- 串流輸出

金鑰只會以 Android Keystore 支援的 EncryptedSharedPreferences 存在**這部裝置**上，不會寫進原始碼、Gradle、Git，也不會被日誌印出。擇要只用這把金鑰向你選定的服務商請求摘要。

攔截採混合方式：

1. **無障礙服務**：盡早從 Chrome、系統預設瀏覽器、WebView 及常見瀏覽器（Firefox、Edge、Samsung 等）讀取完整網址（含路徑）。
2. **本機 VPN**（不是遠端 VPN）：解析 TLS ClientHello 的 SNI 與 HTTP Host。預設**不會**解開 HTTPS。設置裡可選開「解密 HTTPS」：在裝置上產生「擇要 CA」，由你自行安裝為使用者憑證後，才會在本機終止 TLS，讀取完整請求路徑，並可擷取 HTML 正文。關閉此開關或尚未安裝憑證時，行為與先前相同。部分網站或 App（尤其是只信任系統憑證、或憑證固定的服務）可能因此無法連線，系統也可能顯示連線警告。
3. 所有網站都會先攔截並驗證。驗證使用各服務商最輕量的 flash 類模型（DeepSeek `deepseek-flash`、OpenAI `gpt-4o-mini`、Gemini flash-lite、Claude Haiku、Grok mini），關閉深度思考、低強度、溫度 0、最多 8 tokens。已知新聞站清單仍保留在 `NewsHosts.kt`，僅作輔助，不再當作放行條件。

進入過的同一則文章網址會有短暫冷卻，避免無法閱讀原文。

主畫面中間是最近紀錄；右上角「設置」，左上角「其他」（可進入「模型與參數」、重新設定 API Key，也可貼上網址測試擇要頁）。

設置可調：全域、常駐、特定時段、特定 App、顏色、風格、進入按鈕位置、「解密 HTTPS」（預設關閉，須先安裝擇要憑證），以及「擇要過程中退出後繼續生成」（預設開啟）。

## 權限

擇要會申請它實際用到的權限，並在系統與應用內以繁體中文說明：

| 權限 | 用途 |
| --- | --- |
| 本機 VPN（`VpnService`） | 在裝置內轉發流量、辨識目標主機；流量不會送往遠端 VPN 伺服器 |
| 無障礙服務 | 讀取瀏覽器位址列中的完整網址 |
| 網路 | 由應用自行擷取文章，並向你選定的 AI 服務商串流摘要 |
| 前景服務／通知 | 「常駐」時在通知列提示攔截正在執行 |
| 忽略電池優化 | 常駐時適度請求，避免系統把服務殺掉；不會反覆打擾 |
| 查詢已安裝應用 | 讓你在「特定 App」裡多選要攔截的應用 |
| 使用者 CA（自選） | 僅在開啟「解密 HTTPS」時需要；憑證私鑰只存在這部裝置上 |

請只在你信任並自行安裝的前提下開啟無障礙與 VPN。

## 如何建置

本機需要 JDK 17 與 Android SDK（compileSdk / targetSdk 35，build-tools 35.0.0）。`minSdk` 為 26。

在專案根目錄建立 `local.properties`（此檔不會進 Git）：

```
sdk.dir=/你的/Android/Sdk
```

然後：

```bash
export JAVA_HOME=/path/to/jdk-17
./gradlew :app:assembleDebug
```

產出的除錯 APK 位於：

```
app/build/outputs/apk/debug/app-debug.apk
```

可直接安裝到 Android 8.0 或更新的裝置。這是除錯版，尚未簽名為正式上架版本。

## 使用前須知

1. 完成引導並通過金鑰初始化（失敗不會進入主畫面）。
2. 在主畫面或設置中打開「全域」攔截，授權本機 VPN。
3. 到系統設定開啟擇要的無障礙服務，才能取得完整文章路徑。
4. 建議把擇要設為預設瀏覽器，並指定實際要跳轉的瀏覽器。打開任一網址會先看到「驗證中」浮窗；新聞才進擇要頁，其他則照常打開。
5. 若要取得文章的完整路徑與較完整正文，可在設置開啟「解密 HTTPS」，並依指示安裝「擇要 CA」。此項可隨時關閉。
6. 若只想先看介面，可在「其他」貼上新聞網址做測試。
