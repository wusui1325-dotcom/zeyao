# 擇要

擇要是一款 Android 應用：在新聞類網頁真正打開正文之前先攔截，立刻出示摘要頁，並以串流方式寫出 AI 擇要。頁面一出現就有「返回」與「進入」兩個按鈕，不必等模型或文章擷取完成。

- **返回**：關閉擇要頁，不繼續打開原文。
- **進入**：關閉擇要頁，放行原文。
- 摘要為繁體中文短訊，適合數秒內讀完。
- 這是 Wusper 相關的獨立專案，不是 GameHub 的一部分。

目前版本：`0.1.1`

## 運作方式

首次啟動會進入全頁引導：先選擇 AI 服務商（DeepSeek、OpenAI、Google Gemini、Anthropic Claude、xAI Grok），再輸入該服務商的 API Key，然後在載入頁初始化接口並寫入預設生成參數：

- 關閉深度思考
- 高強度／高 reasoning effort（各家按官方欄位對應，能送的就送）
- 溫度 1.2
- 最多 1000 tokens
- 串流輸出

金鑰只會以 Android Keystore 支援的 EncryptedSharedPreferences 存在**這部裝置**上，不會寫進原始碼、Gradle、Git，也不會被日誌印出。擇要只用這把金鑰向你選定的服務商請求摘要。

攔截採混合方式：

1. **無障礙服務**：盡早從 Chrome、系統預設瀏覽器、WebView 及常見瀏覽器（Firefox、Edge、Samsung 等）讀取完整網址（含路徑）。
2. **本機 VPN**（不是遠端 VPN）：解析 TLS ClientHello 的 SNI 與 HTTP Host。若是新聞站，可短暫卡住轉發，讓擇要頁先出現。第一版**不會**對 HTTPS 做中間人解密，也不需要安裝使用者憑證。
3. 新聞站清單寫在 `NewsHosts.kt`，可直接擴充。不在清單裡的網址一律放行。

進入過的同一則文章網址會有短暫冷卻，避免無法閱讀原文。

主畫面中間是最近紀錄；右上角「設置」，左上角「其他」（可重新設定 API Key，也可貼上網址測試擇要頁）。

設置可調：全域、常駐、特定時段、特定 App、顏色、風格、進入按鈕位置，以及「擇要過程中退出後繼續生成」（預設開啟）。

## 權限

擇要會申請它實際用到的權限，並在系統與應用內以繁體中文說明：

| 權限 | 用途 |
| --- | --- |
| 本機 VPN（`VpnService`） | 在裝置內轉發流量、辨識新聞站主機；流量不會送往遠端 VPN 伺服器 |
| 無障礙服務 | 讀取瀏覽器位址列中的完整新聞網址 |
| 網路 | 由應用自行擷取文章，並向你選定的 AI 服務商串流摘要 |
| 前景服務／通知 | 「常駐」時在通知列提示攔截正在執行 |
| 忽略電池優化 | 常駐時適度請求，避免系統把服務殺掉；不會反覆打擾 |
| 查詢已安裝應用 | 讓你在「特定 App」裡多選要攔截的應用 |

請只在你信任並自行安裝的前提下開啟無障礙與 VPN。

## 如何建置

本機需要 JDK 17 與 Android SDK（compileSdk / targetSdk 35，build-tools 35.0.0）。`minSdk` 為 26。

在專案根目錄建立 `local.properties`（此檔不會進 Git）：

```
sdk.dir=/你的/Android/Sdk
```

然後：

```bash
export JAVA_HOME=/path/to/jdk-17
./gradlew :app:assembleDebug
```

產出的除錯 APK 位於：

```
app/build/outputs/apk/debug/app-debug.apk
```

可直接安裝到 Android 8.0 或更新的裝置。這是除錯版，尚未簽名為正式上架版本。

## 使用前須知

1. 完成引導並通過金鑰初始化（失敗不會進入主畫面）。
2. 在主畫面或設置中打開「全域」攔截，授權本機 VPN。
3. 到系統設定開啟擇要的無障礙服務，才能取得完整文章路徑。
4. 用 Chrome 或系統預設瀏覽器打開新聞站文章；應會先看到擇要頁，按鈕立刻可按，摘要逐字出現。
5. 若只想先看介面，可在「其他」貼上新聞網址做測試。
